# 一阶方法改进总结

## 已实施的改进

### 1. Shapley值计算公式优化 ✅
- **归一化改进**: 除以验证集batch size，得到平均贡献
- **批次归一化**: 除以训练batch size，确保不同批次大小可比较
- **温度缩放**: 添加温度参数（可调）以改善区分度

### 2. 加权累积策略 ✅
- **迭代权重**: 后期迭代权重更高（指数衰减：weight = 1 - exp(-iter/100)）
- **最小权重**: 确保早期迭代也有贡献（最小0.1）
- **原理**: 早期梯度不稳定，后期更可靠

### 3. 样本计数和归一化 ✅
- **计数跟踪**: 跟踪每个样本被看到的次数
- **平均归一化**: 保存时对Shapley值进行平均归一化
- **效果**: 避免重复样本过度累积

### 4. 学习率调度 ✅
- **Warmup**: 前100步线性warmup
- **Cosine退火**: Warmup后使用cosine退火
- **效果**: 更稳定的训练，更好的收敛

### 5. 验证集处理改进 ✅
- **验证集轮换**: 每次迭代使用不同的验证样本
- **更大验证集**: 使用多个验证批次（最多8个）
- **效果**: 更稳定的Shapley值估计

### 6. 训练参数优化 ✅
- **训练步数**: 默认增加到2000步
- **验证batch size**: 增加到4
- **权重衰减**: 添加0.01的权重衰减

## 使用方法

### 使用改进的训练脚本
```bash
python scripts/train_improved.py \
    --data_dir ./data/cifar10_simple \
    --output_dir ./results/improved_v1 \
    --num_steps 2000 \
    --batch_size 8 \
    --val_batch_size 4
```

### 评估结果
```bash
python scripts/evaluate_tasks.py --result_dir ./results/improved_v1
```
